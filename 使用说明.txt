于静凯 · AIGC 视觉设计师作品集（项目源文件）

一、怎么运行
1. 双击本文件夹里的「启动网站.bat」，浏览器会自动打开 http://127.0.0.1:5173
2. 关闭弹出的命令行窗口即停止服务
3. 这台机器上 node 来自豆包运行时；换到别的电脑，需要先装 Node 18 以上，再在本文件夹执行 npm install

二、目录说明

public/videos/preview/ 25 条悬停预览（6 秒 / 480 宽 / 静音）

三、声音
- 作品卡悬停预览是静音的：浏览器禁止带声自动播放，且悬停不该突然出声
- 点开作品弹窗自动静音起播，左上角「开启声音」按钮点一下即有声音（再点静音）
- 首屏背景视频与右侧轮播始终静音
- 成片音轨 AAC 96k：25 条合计 132MB，预览 4MB

四、下载权限（已关闭）
- 弹窗播放器的原生控制条不显示下载按钮（controlsList=nodownload）
- 所有视频、封面图右键「图片/视频另存为」被拦截，拖动保存也被禁用
- 关闭了画中画与远程投屏（AirPlay/Chromecast）这两个会外流的通道
- 说明：这是前端层面的遮挡，能挡住访客随手另存；懂技术的人仍可从浏览器网络面板拿到 mp4 地址。
  真要彻底禁止，需要放到服务器后加防盗链（校验 Referer）、签名 URL（带时效）或私有 CDN 鉴权，
  这些在静态站做不到，需要部署环境配合。

五、常见修改
- 改作品标题/描述：改 src/data/works.js 里对应条目的 title / category / desc / tags
- 调精选位置：把 featured 改成 1-4（1 在最左），其余条目不要写 featured 就进全部作品
- 换视频：用同样三档规格转码后覆盖 public 下同名文件即可，无需改代码
- 改完源文件后要重新构建：node node_modules\vite\bin\vite.js build --outDir dist
